# Archivo histórico

Los documentos de esta carpeta se conservan únicamente como registro del
desarrollo del proyecto. Describen la etapa en que el sistema se alojaba en
servicios en la nube (Supabase, Vercel y Firebase), **todos descontinuados**.

No deben usarse para instalar, operar ni auditar el sistema. La documentación
vigente es el [expediente técnico para la OTI](../oti/) y el
[README](../../README.md) del repositorio.

| Documento | Contenido |
| --- | --- |
| `deployment.md` | Guía de despliegue en Vercel (reemplazada por `oti/03_MANUAL_OPERACIONES_Y_RUNBOOK.md`). |
| `oauth_setup.md` | Configuración de Google OAuth a través de Supabase Auth (reemplazada por `oti/04_GUIA_CONFIGURACION_GOOGLE_WORKSPACE.md`). |
| `sprint-1-closeout.md` a `sprint-3-closeout.md` | Actas de cierre de los primeros sprints. |
| `sprint-9-production-launch.md` | Acta del lanzamiento sobre infraestructura en la nube. |
